# 소방서 위치 카탈로그

공개 파일럿의 관할 선택과 GPS 미수신 시 출동 기준점은 소방청 공개 파일인
`소방청_전국소방서 좌표현황(XY좌표)_20240901`에서 가져온다.

- 출처: https://www.data.go.kr/data/15138232/fileData.do
- 기준일: 2024-09-01
- 포함 범위: `유형=소방서`인 215개 관서
- 저장 좌표: 원본 `X좌표=위도`, `Y좌표=경도`
- 서비스 식별자: 원본 번호를 `nfa-0000` 형식으로 고정

`GET /auth/staging/pilot/stations`는 공개 파일럿이 활성화된 경우에만 지역별
목록과 주소·좌표·전화번호·출처 기준일을 반환한다. 사용자가 선택한
`stationId`는 서버 카탈로그에서 다시 검증하며, 임의의 관할명이나 좌표를
세션에 넣을 수 없다.

세션의 `stationLocation.coordinateSource`는 `NFA_PUBLIC_DATA`다. 이 좌표는
대원·차량 GPS가 아니라 소방서 청사의 정적 출동 기준점이며, FE는 실제 기기
GPS가 수신되면 GPS 좌표를 우선한다.
